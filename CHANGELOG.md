# OUTMAX Cut 1.3.0

- Выбор видеобитрейта: 500, 750, 1000, 1065, 1500, 2000 и 2500 кбит/с.
- Стандартное значение — 2500 кбит/с. Метрики битрейта и ожидаемого размера MP4 перед экспортом.
- Независимый битрейт для каждого товара в пакетной сборке, перенос настроек на всю очередь.
- Проверка новых стабильных версий через GitHub Releases, загрузка с проверкой SHA-256, установка по кнопке.
- Резервный запуск в браузере при ошибках загрузки WebView2/.NET и создания окна.
