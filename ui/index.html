Перед установкой завершите монтаж. Текущая очередь не сохраняется при закрытии. Готовые видео остаются на диске.

Из двух исходников — в готовый ролик

  1. Добавьте модель на ногах и демонстрацию в руках. Порядок задают подписанные поля.
  2. Проверьте квадратный кадр. Ползунок сдвигает его выше или ниже.
  3. Для похожей съёмки оставьте тайминг эталона. Для других дублей выберите удаление пауз.
  4. Нажмите «Собрать видео». После обработки посмотрите результат и сохраните его.

Шаблон сохраняет длительность 22,53 с, ускорения, переходы и короткий финал из начала видео модели. Чтобы получить чистый фон в конце, начинайте съёмку модели с пустого фона.

Исходный проект использует Film Impact Lens Blur. Здесь — самостоятельное приближение эффекта. Морфинг доступен отдельно; на сильно разных планах возможны искажения.

В пакетном режиме добавьте общую папку с подпапками товаров. В каждой ожидаются два видео. Нажмите на товар, чтобы просмотреть исходники и изменить его настройки. Если файлов больше двух — выберите пару из списков. Очередь экспортируется в выбранную папку по одному ролику; ошибка одного товара не останавливает остальные.
